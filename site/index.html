紙芝居DSLの版を選ぶ

DSL 3.2と4.0は、どちらも正式にサポートしています。ただし台本形式と制作環境は異なり、 相互に同じ文法としては読み込めません。既存作品を維持するか、新しい制作基盤を使うかを基準に選んでください。

既存作品を継続 3.2

TXT台本と3.2.xアプリを使い続ける

すでに上映している作品や教材を保守する方、従来のアプリとツールチェインを継続利用する方にはDSL 3.2をおすすめします。

対象と形式
TMPose紙芝居3.2.xと、先頭にkamishibai=3.2を書く.txt台本。3.1宣言も読み込めます。
主な利用場面
既存作品・体験会教材の修正、汎用SB3への台本読込、従来素材の継続利用。
互換性
3.2.xは3.1／3.2台本を受理します。DSL 4.0のYAMLやSource Graphとは文法互換ではありません。
4.0を選ぶ基準
新規projectでYAML、複数source、preview／buildの一体化を使いたい場合。
3.2文書の一覧へ ファイル作成マニュアル コマンドリファレンス
新規制作を開始 4.0

YAML projectと4.0 toolchainで新しく作る

新しい作品をproject単位で制作し、Schema検証からpreview、配布用buildまでを一貫した手順で扱う方にはDSL 4.0をおすすめします。

対象と形式
TMPose紙芝居4.0系列と、kamishibai: '4.0'を宣言するYAML。新規sourceは.k4.ymlを推奨します。
主な利用場面
新規project、Source Graphによる台本分割、Web／CLI preview、自己完結SB3 build。
互換性
JSON Schemaと意味検証を前提とする別系列です。3.2のTXT台本をそのまま読み込む形式ではありません。
3.2を選ぶ基準
既存のTXT台本や3.2.xアプリ・教材を、移行せず安定して保守したい場合。
4.0文書の一覧へ 台本作成ガイド Schemaリファレンス
