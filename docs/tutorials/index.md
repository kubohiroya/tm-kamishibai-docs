対象バージョン: `4.0.0-rc.3`（公開プレリリース）

このチュートリアルでは、公開サンプルをポーズで遊ぶ方法と、配布されたスターターから自分の作品を
作る方法を説明します。紙芝居で遊びたい人と、自分の台本を作りたい人では最初にすることが違います。
次の表から、いまの目的に合う方を選んでください。迷ったら、先に「紙芝居で遊ぶ」へ進みます。

完成例は、教室で「地震だ！」と気づいた参加者が、自分の身を守るために丈夫な机の下へ入り、両手で
頭を守るポーズを取り、最後にできたことを確認する4場面の作品です。「何が起きたか」「なぜ動くか」
「どんなポーズをするか」「何を達成したか」を一続きで確かめられます。

| やりたいこと              | こんな人向け                             |     時間 | 最初にすること                 | できあがり                          |
| ------------------------- | ---------------------------------------- | -------: | ------------------------------ | ----------------------------------- |
| [紙芝居で遊ぶ](play.md)   | 作品を見て、ポーズで参加したい           | 10〜15分 | サンプル作品を開く             | 作品へ参加し、最後まで遊べる        |
| [紙芝居を作る](create.md) | セリフや絵を変えて、自分の作品を作りたい | 60〜90分 | 完成例を遊び、スターターを開く | セリフや登場人物を変えたSB3を作れる |

## 紙芝居で遊びたい

用意するものは、Webブラウザーを使えるパソコンまたはタブレットです。ポーズで参加する作品では、
カメラと全身を映せる少しの空間も使います。カメラを使わない場合は、キーや画面のタッチで参加できる
作品を選びます。台本やプログラムの知識はいりません。

1. 公開サンプル作品を開く
2. タイトルから紙芝居を始める
3. 必要なときだけカメラを許可する
4. 画面の見本に合わせてポーズを取る
5. 物語を最後まで進める

[紙芝居で遊ぶチュートリアルを始める](play.md)

## 自分の紙芝居を作りたい

用意するものは、配布されたスターターと非埋め込みStandard SB3、文字を編集できるエディター、
対応するChromium系Webブラウザーです。Node.js、pnpm、ターミナルは使いません。最初は絵や
ポーズモデルを作らず、Scratchのブロックも追加しません。

1. これから作る完成例を遊ぶ
2. Standard SB3をTurboWarp Editorで開き、緑の旗を押す
3. 「開く」からスターターの作品フォルダーを選ぶ
4. セリフを一行だけ変え、自動検査と反映を確かめる
5. 背景や登場人物を一つずつ追加する
6. 診断されたエラーを直し、メニューから配布用SB3を作る

[紙芝居を作るチュートリアルを始める](create.md)

## 公開プレリリースについて

この手順は、`4.0.0-rc.3`と同じ版のサンプル、スターター、実行環境を使います。
安定版`4.0.0`の公開後に操作名や配布物が変わった場合は、このページの対象バージョンを確認してください。

## 最初は扱わないこと

次の内容は、最初の作品ができてから必要に応じて調べます。

- すべての台本命令と細かな制約
- 複数の台本を組み合わせる大きな作品
- 古い台本からの移行
- ポーズモデルの学習
- 紙芝居アプリ本体や機能拡張の開発

台本の詳しい書き方は[紙芝居DSL 4.0 台本作成ガイド](../dsl-author-guides/dsl-4.0-author-guide.md)、
項目や命令の正確な形は、検索用の
[DSL 4.0 Schemaリファレンス](../dsl-author-guides/dsl-4.0-schema-reference.md)で調べられます。

## カメラを使う前に

カメラ映像は、ポーズを判定するために端末内で使います。撮影や配信をする場合は、映る人の同意を確認し、
個人情報や無関係な人が映らない背景を選びます。カメラを許可したくない場合は、許可が必要になる
直前まで手順を確認し、そこで止められます。

## 防災表現について

この作品は、教室内に丈夫な机がある場面に限定した練習です。実際の地震では、頭を保護し、倒れそうな
家具や落下物から離れ、安全な空間または丈夫な机の下などで身の安全を確保します。周囲の状況に応じて
判断してください。表現は[気象庁「地震について」](https://www.jma.go.jp/jma/kishou/know/faq/faq7.html)と
[消防庁「地震防災マニュアル」](https://www.fdma.go.jp/relocation/bousai_manual/occ/occurrence111.html)を
参考にしています。
