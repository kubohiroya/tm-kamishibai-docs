紙芝居で遊びたい人と、自分の台本を作りたい人では、最初にすることが違います。
次の表から、いまの目的に合う方を選んでください。迷ったら、先に「紙芝居で遊ぶ」へ進みます。

| やりたいこと              | こんな人向け                             |     時間 | 最初にすること                 | できあがり                           |
| ------------------------- | ---------------------------------------- | -------: | ------------------------------ | ------------------------------------ |
| [紙芝居で遊ぶ](play.md)   | 作品を見て、ポーズで参加したい           | 10〜15分 | サンプル作品を開く             | ポーズを成功させ、最後まで遊べる     |
| [紙芝居を作る](create.md) | セリフや絵を変えて、自分の作品を作りたい | 60〜90分 | 完成例を遊び、スターターを開く | セリフを変えた作品をプレビューできる |

## 紙芝居で遊びたい

用意するものは、カメラを使えるパソコンまたはタブレットと、全身を映せる少しの空間です。
台本やプログラムの知識はいりません。

1. サンプル作品を開く
2. タイトルから紙芝居を始める
3. 必要なときだけカメラを許可する
4. 画面の見本に合わせてポーズを取る
5. 物語を最後まで進める

[紙芝居で遊ぶチュートリアルを始める](play.md)

## 自分の紙芝居を作りたい

用意するものは、配布されたスターター、文字を編集できるエディター、Webブラウザーです。最初は絵や
ポーズモデルを作りません。Scratchのブロックも追加しません。

1. これから作る完成例を遊ぶ
2. スターターの台本ファイルを開く
3. セリフを一行だけ変えて保存する
4. プレビューで画面が変わったことを確かめる
5. 背景や登場人物を一つずつ追加する
6. エラーの場所を直し、完成した作品を出力する

[紙芝居を作るチュートリアルを始める](create.md)

## 最初は扱わないこと

次の内容は、最初の作品ができてから必要に応じて調べます。

- すべての台本命令と細かな制約
- 複数の台本を組み合わせる大きな作品
- 古い台本からの移行
- ポーズモデルの学習
- 紙芝居アプリ本体や機能拡張の開発

台本の詳しい書き方は[紙芝居DSL 4.0 台本作成ガイド](../dsl-author-guides/dsl-4.0-author-guide.md)、
項目や命令の正確な形は
[DSL 4.0 Schemaリファレンス](../dsl-author-guides/dsl-4.0-schema-reference.md)で調べられます。

## カメラを使う前に

カメラ映像は、ポーズを判定するために使います。撮影や配信をする場合は、映る人の同意を確認し、
個人情報や無関係な人が映らない背景を選びます。カメラを許可したくない場合は、許可が必要になる
直前まで手順を確認し、そこで止められます。
